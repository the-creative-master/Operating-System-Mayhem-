# Operating System Mayhem

A single-file, desktop-first arcade boss rush starring operating-system history. Open `index.html` in a modern browser; the game has no build step and keeps progress in browser local storage.

## What's in the overhaul

- A 98-boss archive spanning Windows, macOS and Linux, including a 24-distro Linux expansion.
- Each boss gets three exclusive signature attacks plus only two shared attacks within its OS ecosystem.
- Invert resets you to a separate 200-level Veteran ladder with escalating power; mirror bosses include Windows 98 at 1.1 billion HP, Tails at 200 trillion HP, and Arch Linux at one quadrillion HP. Normal CPU progress is preserved when you leave Invert.
- A cinematic Legion sequence and four named combat minibosses; each gives XP for five wins, then reboots for two hours.
- Dash through a live attack for a **Perfect Evade**: the boss is exposed for 2.2 seconds, and your shots hit 50% harder.
- Desktop controls are the default. Touch controls are off until enabled in Settings.
- The GitHub creator badge links to [the-creative-master](https://github.com/the-creative-master).

Controls and save progress are shown in-game. Press Escape to back out of settings or the miniboss select screen. The main menu’s Next Fight button resumes the campaign.
